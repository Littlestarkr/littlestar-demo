키오스크가 먼저 ‘누구세요?’라고 묻고, 내 메뉴만 보여 줍니다.

10초는 목표 단골 주문 경로의 결제 포함 설계 목표이며 프로토타입 실측으로 검증할 예정입니다. 처음 온 손님은 지금과 같은 일반 주문을 그대로 씁니다.

직접 비교해 보기 투자자용 요약

문제: 나를 알아보는 건 맨 마지막

지금 키오스크는 메뉴 탐색 → 옵션 → 포장 → 결제 → 포인트 번호 → 진동벨 순서입니다. 매일 같은 메뉴를 먹는 단골도 매번 처음부터 찾고, 고객이 누구인지는 맨 끝 번호 입력에서야 알게 됩니다.

현장 실측(개 매장 건, , 피크타임 단독 손님, 첫 터치~결제 완료). 범위 ~초. 고령 이용자 1건(초)을 빼도 평균 초.

해결: 단골손님은 식별을 맨 앞으로

키오스크 첫 화면에는 [단골 주문]과 [일반 주문] 두 길이 있습니다. 일반 주문은 지금 키오스크와 같은 순서 그대로라 처음 온 손님도 평소처럼 주문하고, 단골 주문은 미리 등록한 메뉴(최대 5개)를 바로 보여 줍니다. 단골 주문 바로 밑의 작은 [단골메뉴 등록하기]로 처음 한 번 등록합니다.

  1. 단골손님 선-식별‘단골 주문’을 누르면 바로 고객 확인: 기본은 QR·휴대폰 태그 또는 미리 등록한 고객번호 6자리, 보조로 휴대폰 번호(010 뒤 8자리).
  2. 3-Track 주문① 대표 메뉴 1터치 ② 나의 메뉴 5개 중 선택 ③ 동료 메뉴 한 번에
  3. 결제등록해 둔 결제수단·포인트 사용·적립 방식이 자동으로 적용(바꿀 수도 있음)
  4. 폰 알림진동벨 대신 음료가 준비되면 폰으로 알림

목표 단골 주문 경로 기준 식별~주문확정 초, 결제 포함 초 이내 (설계 목표, 프로토타입 실측으로 검증 예정. 일반 주문은 지금 키오스크와 같은 시간)

주문은 앱 없이 키오스크에서, 등록은 처음 한 번. 단골 메뉴는 키오스크 첫 화면의 [단골메뉴 등록하기](휴대폰 번호로 본인 확인 → 메뉴 최대 5개 → 결제수단), 일반 주문 결제 뒤 ‘다음엔 단골로 등록해 보세요’ 안내, 웹·앱, 자녀 대리 등록(준비 중) 중 편한 곳에서 등록합니다.

주문 순서 비교 체험

단골메뉴 등록 시연용

주문은 앱 없이 키오스크에서, 등록은 처음 한 번. 여기서 등록한 메뉴로 리틀스타 체험을 해 볼 수 있습니다.

이 화면은 시연용입니다. 실제 매장 키오스크와 연동되지 않으며, 이름·전화번호·결제정보를 받지 않습니다. 등록 내용은 이 기기 브라우저에만 저장됩니다.

주문 절차 비교

차이는 단 하나, ‘나를 알아보는 순서’입니다.

기존 키오스크 결제 전 약 13단계

  1. 매장/포장 선택
  2. 카테고리 선택
  3. 메뉴 탐색
  4. 메뉴 선택
  5. 온도·옵션
  6. 장바구니
  7. 광고 팝업
  8. 주문 확인
  9. 일회용품
  10. 스탬프 방법
  11. ★ 번호 입력(식별) ← 식별이 여기
  12. 결제 수단
  13. 카드 삽입·승인

리틀스타 4단계

  1. ★ 단골 주문 → 고객 확인 (QR·태그 / 고객번호 6자리 / 보조: 휴대폰 번호)
  2. 나의 메뉴 확인 → 주문하기(1터치, 수량 ± 가능)
  3. 등록한 결제수단이 자동 선택된 화면에서 [결제하기]
  4. 폰 알림(진동벨 대신)

단골주문은 식별이 11번째 → 1번째로

기존형 단계는 A매장 키오스크 주문절차도(14화면)를 바탕으로 정리했습니다. 체험 페이지의 기존형 화면은 이 순서를 그대로 따릅니다(특정 브랜드 디자인 아님).

장기 과제 선불 자동결제를 켜면 리틀스타 3단계 ‘결제’가 2단계 주문 확정과 합쳐집니다. 규제 확인 후 추진하며 현재 계획(MVP)에는 없습니다.

  • 단골은 시간: 매일 같은 메뉴를 처음부터 찾지 않습니다.
  • 어르신은 접근성: 메뉴판 탐색 대신 번호만 누릅니다.
  • 점주는 피크타임: 대기열 이탈과 키오스크 증설비 부담을 줄입니다.
