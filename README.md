# 리틀스타 웹 체험

단골 손님이 키오스크에서 등록해 둔 메뉴로 빠르게 주문하는 흐름을 직접 해 보는 체험 페이지입니다.

- 체험 주소: https://littlestarkr.github.io/littlestar-demo/
- 이 사이트는 이름·전화번호·결제정보를 받지 않습니다. 체험 기록과 등록 메뉴는 이 기기 브라우저에만 저장됩니다.
- 화면의 수치 중 현장 실측(5개 매장 21건)과 설문(n=68)은 자체 소규모 조사이며, 10초는 설계 목표입니다. 시장 규모·요금·손익은 가정·추정입니다.

## 고치는 법 (작가님용)
- 수치: `src/data/facts.js`, 체험 메뉴: `src/data/menu.js`, 화면 문구: `src/index.html`
- 고친 뒤 `python3 build.py`를 실행하면 맨 위 `index.html`(공개되는 파일)이 다시 만들어집니다.
